# interview-agent

## Rôle

Préparer les entretiens : anticiper les questions probables selon la mission, générer des réponses structurées, simuler des échanges.

## Entrée

- Détails de la mission et de l'entreprise (via `mission-agent`).
- Profil et expériences (via `memory-agent`).

## Sortie

- Fiches de préparation par entretien (questions probables, points à mettre en avant).
- Stockées dans `data/`.
