# dashboard-agent

## Rôle

Fournir une vue d'ensemble consolidée : pipeline de candidatures, missions en cours de qualification, actions à faire, métriques (taux de réponse, délais).

## Entrée

- Données agrégées de `mission-agent`, `recruiter-agent`, `interview-agent`.

## Sortie

- Vue consolidée (consommée par `frontend/` une fois développé).

## Statut

Non implémenté. Dépend des autres agents pour avoir des données à afficher.
